# Solar Packaging

This repository allows you to publish packages for **Solar Lang**.

Follow the steps below carefully to ensure your package is accepted and published without delays.

---

## 🔐 Token Generation (Required)

> **This step is required to verify your identity.**

1. Open the token generation website listed in **`LINKS.md`**.
2. Fill out the form.
3. Click **Generate Token**.
4. Save your token securely — you’ll need it later.

Once this is done, you’re ready to publish.

---

## 📦 Publishing a Package

1. **Fork** this repository.
2. **Sync your fork** so it’s up to date with the main repository
   (GitHub will show something like:
   *“This fork is X commits behind DavidTheD3veloper/Solar-Packages”* → click **Sync fork**).
3. In your fork, create a JSON file inside the **`pkgs/`** directory named:

   ```
   your-package-name.json
   ```
4. Copy the JSON template from the documentation
   (the link is available in **`LINKS.md`**).
5. **Fill out all fields accurately and completely.**
6. Commit your changes with a clear commit message.
7. Open a **Pull Request** to this repository.
8. **Complete the Pull Request template correctly.**
9. Wait for maintainers to review your submission.
10. Once merged, wait a few days — your package will then appear in the package list.

---

## ⚠️ Important Notes

* Incomplete or incorrect submissions may be **rejected or delayed**.
* Make sure your fork is **up to date** before opening a Pull Request.
* Follow the JSON schema **exactly** as described in the documentation.
